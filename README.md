# 🎯 Quiz App (MERN Stack)

A full‑stack **Quiz Application** built using the **MERN stack** that allows users to answer multiple‑choice questions, track scores, and view results in a clean, responsive UI.

This project is suitable for **learning MERN**, **college projects**, and **job portfolios**.

---

## 🚀 Features

* 🧠 Interactive quiz with multiple questions
* ⏱️ Timer‑based questions
* 📊 Score calculation & result screen
* 🔄 Next / Previous question navigation
* 💻 Responsive UI (mobile + desktop)
* ⚡ Fast frontend using React (Vite)

---

### Frontend

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Yagvendr/Quiz-app.git
cd Quiz-app
```

---

### 2️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

Frontend will run on:

```
http://localhost:5173
```

---

### 3️⃣ Backend Setup

```bash
cd backend
npm install
npm start
```

Backend will run on:

```
http://localhost:5000
```

---

### 4️⃣ Environment Variables

Create a `.env` file in the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```
